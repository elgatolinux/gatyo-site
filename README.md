# gatyo-site

Landing page for Gatyo. React, Vite, Tailwind, GSAP and Lenis, deployed to GitHub Pages.

- `npm run dev` / `npm run build`
- All copy lives in `src/i18n/dict.ts`.
- Background art is procedural: `CHROME_PATH=/path/to/chrome node tools/gen_art.mjs`.

Unofficial project, not affiliated with Mojang or Microsoft.
